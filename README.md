# 健康管理アプリ
毎日ストレッチを行い、成果を可視化し健康へつなげていくアプリです。
仕事(勉強)時間を設定し、終了後決められたストレッチを行ってもらいます。
アカウント設定時に、ストレッチを行う期間・仕事(作業)時間・一日のストレッチ回数を設定します。

- Laravel Framework 13.23.0
- Composer 2.9.8

# 機能一覧
## ユーザー認証機能
- メールアドレス＋パスワードによるログイン
- アカウント作成（メール／パスワード
- ログアウト
- 入力バリデーション 
- 入力エラー時のメッセージ表示

## ナビゲーション（ヘッダー）機能

- サインアウト後、ログイン画面へ遷移
- home/settingアイコンの表示
- アカウント設定機能への遷移 

## タイマー管理機能

- 作業タイマーの開始／停止
- 経過時間の表示
- タイマー終了時の通知表示
- 通知ON／OFF切り替え

## ストレッチ・運動タスク管理機能
- ストレッチタスク一覧表示
- タスク内容／所要時間表示／効果
- タスク実施記録の保存

## 活動記録・可視化機能
- 今日のストレッチ実績表示
- 日別の活動記録表示
- 期間グラフ表示

## アカウント設定機能

- メールアドレス・パスワードの表示
- メールアドレス変更
- パスワード変更
- 1日の目標ストレッチ回数・ストレッチ期間・タイマーの表示
- 1日の目標ストレッチ回数の設定
- ストレッチ期間の設定
